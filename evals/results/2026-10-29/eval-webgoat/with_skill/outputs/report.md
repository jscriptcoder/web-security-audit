# WebGoat and WebWolf — source-only security review

Date: 2026-10-29. Target: `C:/Users/User/Projects/web-security-audit-workspace/webgoat`. No Git revision was available. The manifest declares version `2026.6-SNAPSHOT`, Java 25 and Spring Boot parent 4.1.1; deployed versions were not verified.

The most consequential issues are in the shared platform: reinstated default administrator credentials, lessons executing with platform process/database privileges, mailbox authorization/rendering failures, and WebWolf upload/trace isolation failures. Deliberately vulnerable exercises are separated below. Their intended exploits do not make effects on other students, administrators or host data automatically isolated.

**Evidence standard.** The application, build, tests and deployed services were not run. No network/advisory lookup was performed. “Confirmed” means the stated root cause and bounded effect follow from source, not runtime reproduction. “Supported” means a material browser/framework/deployment condition remains unverified. Severity assumes a reachable multi-user training instance; single-user loopback use reduces exposure. Suggested regression checks are future checks, not completed tests. Secrets/challenge answers are omitted. Paths and line numbers identify this snapshot.

**Architecture.** WebGoat authenticates learners/admins using the container user table and registers lessons in the same application. Lesson JDBC connections change their default schema on a shared datasource. WebWolf shares the account database, but has a separate context/session cookie, and provides file hosting, request inspection and a JWT utility. Both launch in one JVM. Properties default to loopback; Docker supplies `--server.address=0.0.0.0`. Actual port publishing, reverse proxies, TLS, mounts and external identity-provider settings are unknown. Docker's non-root user is useful but does not isolate learners from application-owned data.

### P01 — Startup reinstates a universal administrator credential

**High · Confirmed · CWE-798.** [container/users/DefaultUserInitializer.java:25](C:/Users/User/Projects/web-security-audit-workspace/webgoat/src/main/java/org/owasp/webgoat/container/users/DefaultUserInitializer.java:25) defines a fixed administrator credential; lines 33–44 save it with the admin role even if the account already exists. **Impact/limits:** a reachable attacker knowing the source default can access admin data and reset other accounts after startup. This is actual platform administration, unlike lesson “admin” fixtures. Internet reachability was not established.

**Fix:** opt-in local demo provisioning; random/operator-provided initial administrator secret; never overwrite existing credentials on startup. **Regression:** change the password and restart twice; the new password persists and the default fails.
